# 公众号结构模板

## 测评型

1. 我怎么测（环境、样本、标准）
2. 每关一个真实场景
3. 输入、输出、截图
4. 失败点
5. 评分
6. 谁该用/谁别用

## 教程型

1. 能解决什么具体问题
2. 准备条件
3. 完整步骤
4. 每步截图
5. 可复制提示词
6. 验收标准
7. 常见坑

## 热点解读型

1. 发生了什么
2. 官方证据
3. 为什么重要
4. 对谁有影响
5. 普通人怎么用
6. 边界和风险

## 变现拆解型

1. 案例事实
2. 收入从哪来
3. 成本和门槛
4. 可复制动作
5. 不可复制因素
6. 三类人建议

## 工具对比型

1. 使用场景
2. 参与工具
3. 关键指标
4. 实测过程
5. 结果对比
6. 选择建议

## 结尾模板

- 用 3-5 条总结可执行动作；
- 明确风险和边界；
- 不写空洞展望。
