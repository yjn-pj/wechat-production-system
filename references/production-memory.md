# 生产记忆与复盘

## 初始偏好档案

在 `~/.codex/skills/wechat-production-system/PROFILE.md` 维护账号级偏好。没有档案时，首次正式写稿前创建。

推荐字段：

```yaml
account_name:
default_reader:
default_persona: # 例如：AI变现研究者 / 普通人向技术拆解者
voice:
do:
dont:
title_style:
visual_style:
image_backend:
screenshot_habits:
citation_style:
sensitive_topics:
```

## 历史偏好沉淀

每次成稿后，如果有稳定偏好，更新 `PROFILE.md`。只记录重复出现三次以上的偏好，避免一次反馈造成过拟合。

示例：

```yaml
voice: 通俗、直接、场景优先，不用行业大词
visual_style: 低AI味、编辑部纸感、黑板报、工作台，避免蓝紫科技风
title_style: 有冲突和具体收益，正文必须兑现
evidence: 热点和产品事实必须有真实截图
```

## 文章索引

维护 `production-memory/article-index.md`：

```text
日期 | Slug | 标题 | 类型 | 主图风格 | 核心数据 | 保留 | 禁用
```


## 复盘规则

- 24 小时看首屏和分享，72 小时看完读和收藏；
- 标题好但完读差：开头或结构有问题；
- 完读好但分享差：观点不够锐或转发理由不清；
- 收藏高但留言少：实用性强，争议性弱；
- 图多但完读差：图没有降低理解成本；
- 不根据单篇数据推翻账号定位；
- 连续三篇验证同类问题后才升级为规则。
