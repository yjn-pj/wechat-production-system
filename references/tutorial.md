# 教程型文章规范

## 必备内容

- 适用人群；
- 前置条件；
- 工具清单；
- 每一步操作；
- 每一步截图；
- 可复制提示词；
- 验收标准；
- 常见错误；
- 成本和时间；
- 替代方案。

## 提示词模板结构

```text
角色：
目标：
背景：
输入材料：
任务步骤：
输出格式：
质量要求：
禁止事项：
人工确认点：
```

## 验收标准示例

- 能得到某个文件；
- 每个结论有来源；
- 不改动无关内容；
- 人工审核时间减少；
- 能重复运行三次；
- 失败时能恢复。

## 禁止

- 只写“打开网站，使用 AI”；
- 没有截图；
- 没有模板；
- 没有失败处理；
- 混淆网页端和 CLI 端。
